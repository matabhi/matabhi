ABHI NURSILO — HORIZONTAL PORTFOLIO / PROTOTYPE 02

HOW TO OPEN
Extract this ZIP and open index.html in Chrome, Edge, or Firefox.
No hosting, installation, build tools, subscriptions, or accounts required.

HOW IT WORKS
- Scroll wheel or trackpad anywhere on timeline: horizontal movement with inertia.
- Hover over a project: its image appears immediately, with no animation, border, angle, or shadow.
- Each numbered project has a short text excerpt and a looping placeholder GIF.
- Click a project: its full project documentation expands beside it.
- Hover the expanded project and wheel: its content scrolls vertically.
- Move outside expanded project and wheel: horizontal timeline navigation resumes.
- The bottom-left name returns to the start; ABOUT opens a simple information card.
- Mobile: swipe sideways; swipe vertically within an expanded project.

EDITING
Project text, images, years: script.js, at top, in the projects array.
Styles and spacing: styles.css.
Placeholder animated GIFs and drawings: assets/.

IMAGES
All placeholder images were generated from simple abstract shapes and are NOT your work.
Replace them with your photos, sketches, GIFs, or optimized WebP animations.
GIFs can be large; for finished site consider animated WebP or MP4 for performance.

PUBLISHING LATER
The files are GitHub Pages-compatible. Create a public repository named
YOURUSERNAME.github.io and upload everything at its root, then enable GitHub Pages
under Settings -> Pages -> Deploy from branch -> main / (root).

NOTES
- No font CDN, framework, paid services, or hosting required for local use.
- Reduced-motion preference disables custom wheel inertia.
- Example project descriptions and content are placeholders.
